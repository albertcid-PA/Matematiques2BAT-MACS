# Preparació d'exàmens

En aquest bloc trobaràs, per a cada examen, el **temari que entra**, un **itinerari de pràctica** i una **comprovació final**. L'objectiu no és memoritzar un guió, sinó saber decidir quin procediment cal aplicar en cada situació.
