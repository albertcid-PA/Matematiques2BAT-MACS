# Laboratori de mates

Aquest apartat reuneix les eines interactives del bloc d'àlgebra lineal. Serveixen per comprovar el procediment després d'haver intentat els exercicis manualment.

| Eina | Què permet fer |
|:--|:--|
| [**Resolució de sistemes**](resolucio-sistemes.md) | Resoldre sistemes de dues o tres incògnites amb el mètode de Gauss i justificar si són SCD, SCI o SI. |
| [**Calculadora de matrius**](calculadora-matrius.md) | Fer operacions amb matrius i resoldre equacions i sistemes matricials amb el procediment justificat. |

!!! tip "Com utilitzar el laboratori"
    Intenta primer els càlculs en paper. Després introdueix les dades per comparar les operacions, els passos de resolució i el resultat final.
