# Laboratori de mates

Aquest apartat reuneix les eines interactives del bloc de càlcul. Serveixen per comprovar el procediment després d'haver intentat els exercicis manualment.

| Eina | Què permet fer |
|:--|:--|
| [**Analitzador de funcions**](analitzador-funcions.md) | Estudiar funcions ordinàries, definides a trossos i amb valor absolut seguint els vuit passos dels apunts. |
| [**Derivador pas a pas**](derivador-pas-a-pas.md) | Derivar una expressió i veure l'aplicació de les regles i les simplificacions línia a línia. |

!!! tip "Com utilitzar el laboratori"
    Intenta primer el procediment en paper. Després introdueix la funció per comparar els passos, detectar on t'has equivocat i corregir la resolució.
