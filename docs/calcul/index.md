# Càlcul

En aquest bloc repassarem les eines de càlcul diferencial de primer de batxillerat i les aplicarem a l'estudi de funcions i als problemes d'optimització.

## Temes

1. [**Repàs de límits i derivades**](repas-limits-derivades/index.md) — interpretació i càlcul de límits, taxa de variació mitjana, derivada i regles de derivació.
2. [**Aplicacions de les derivades**](aplicacions-derivades/index.md) — derivabilitat, creixement i extrems, representació de funcions i optimització.

- [**Solucionari desplegable**](per-practicar/solucionari.md) — una única pàgina per consultar la solució de cada exercici i de cada problema PAU sense veure les altres.
