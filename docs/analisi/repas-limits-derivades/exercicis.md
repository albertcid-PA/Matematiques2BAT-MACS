# Repàs de límits i derivades: exercicis

Els exercicis estan agrupats per tipus. Abans de començar cada derivada, identifica si necessites una fórmula elemental, una operació entre funcions o la regla de la cadena.

!!! note "Apartat en construcció"
    Els exercicis de límits s'afegiran quan redactem el repàs de límits. Aquesta pàgina acabarà reunint tots els exercicis del tema.
