# Matemàtiques Aplicades a les Ciències Socials II

Aquest repositori conté els apunts web de **Matemàtiques Aplicades a les Ciències Socials II** de segon de batxillerat. El material està organitzat per blocs i inclou explicacions, exemples resolts, exercicis, problemes PAU i recursos per preparar els exàmens.

## Web dels apunts

Consulta el material publicat a **[albertcid-pa.github.io/Matematiques2BAT-MACS](https://albertcid-pa.github.io/Matematiques2BAT-MACS/)**.
